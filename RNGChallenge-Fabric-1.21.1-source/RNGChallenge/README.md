# RNG Challenge — Fabric 1.21.1

Новый проект с нуля на Java 21 и Fabric.

## Сборка
1. Установите JDK 21.
2. Установите Gradle 8.8 или используйте Gradle Wrapper, созданный вашей средой.
3. В корне проекта выполните:

   `gradle build`

4. Готовый JAR будет в `build/libs/`.

## Установка
Для мультиплеера серверу и каждому клиенту-участнику нужна совместимая установка мода.
Поместите основной `rng-challenge-1.0.0.jar` в папку `mods`.

## Текущий статус
Это стартовая основа проекта, а не завершённый релиз. В ней заложены команды,
персональные игровые сессии, базовый цикл заданий, таймеры и выдача алмазов.
Полный набор заданий, 49 наказаний, клиентский HUD, индивидуальные звуки,
корректная очередь наград, полноценная регистрация событий добычи/крафта/убийств,
персистентная обработка смерти при отключении и расширенная очистка временных
объектов требуют следующих этапов реализации и тестирования.
