# RNG Challenge — этап 1: ядро сессий

В архиве находится обновлённый `RNGChallenge.java`.

## Команды
- `/rngstart` — запустить себя.
- `/rngstart <ник>` — запустить игрока (OP).
- `/rngstart team <игроки>` — запустить выбранных игроков (OP).
- `/rngstart all` — запустить всех онлайн (OP).
- `/rngstop` или `/rngstop <ник>` — остановить сессию.
- `/rngskip` или `/rngskip <ник>` — засчитать провал текущего задания.
- `/rngstats` — показать статистику.
- `/rngsound on|off` — настройка звука в текущей сессии.

## Честный статус
Это промежуточный этап. В нём есть регистрация команд, персональные сессии,
учёт активных тиков и 30-секундная передышка через методы завершения задания.
Реальный генератор/проверка заданий, немедленная выдача первого квеста,
награды, наказания, HUD, звуковые файлы, клиентские эффекты и обработка
дисконнекта ещё не реализованы.

## Применение
Замени `src/main/java/ru/rngchallenge/RNGChallenge.java` этим файлом.
Затем запусти `./gradlew build` (Windows: `gradlew.bat build`) и пришли
полный текст ошибки, если сборка завершится неудачно.
